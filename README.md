# Radar Inteligente de Licitaciones Biomédicas

Entrega final - Curso AI Automation

Automatización con **n8n + Airtable + Google Gemini + HITL (Human-in-the-Loop)** que detecta licitaciones públicas de equipamiento médico, las analiza con IA y arma un flujo de aprobación humana antes de avanzar comercialmente.

**Autora:** Paula Vasquetto

## Objetivo
Rastrear licitaciones públicas de equipamiento médico y extraer automáticamente (con IA) organismo comprador, equipo, cantidad, presupuesto, provincia, fecha límite, requisitos técnicos y prioridad comercial (Alta/Media/Baja). Solo avisa cuando hay una oportunidad relevante para la empresa configurada (BioTecMed Argentina S.A., datos ficticios de demo), eliminando la revisión manual de cada publicación.
